Tutorial de uso

Este espaço reúne os passos principais para usar a biblioteca com rapidez, tanto no computador quanto no celular.
1. Fazer empréstimos
Abra a página Empréstimos, escaneie o livro e a carteirinha do aluno e confirme o empréstimo.
2. Registrar devoluções
Na lista de empréstimos, use o botão Devolver para encerrar o movimento e atualizar o status.
3. Consultar acervo
Na página Acervo você encontra livros, exemplares disponíveis e informações rápidas para localizar cada item.
4. Ver relatórios
Se estiver logado como administrador, a página Relatórios mostra gráficos e exportações para análise.
